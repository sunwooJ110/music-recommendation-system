# Generated artifacts

Running the notebooks creates intermediate datasets and trained artifacts in this directory, including:

```text
preprocessed_reviews.csv
preprocessed_metadata.pkl
tfidf_embedding_matrix.npz
tfidf_vectorizer.joblib
popularity_model_top_items.csv
svd_collaborative_instrument2music.joblib
```

These files are reproducible from the source notebooks and raw data, so they are intentionally excluded from Git.
